# Battle-Tested Patterns

Production incidents on `miyakodeit.com` and `netsujo.jp` that shaped this plugin's defaults.

## Why this file exists

Generic SEO advice is too generic. This plugin's defaults are calibrated by real GSC alerts, real ChatGPT citation events, and real "we noticed too late" incidents. Each defaults to **caught in first scan** going forward.

---

## Incident 2026-05-10: Fake sitemap entry shipped

**Site**: miyakodeit.com
**Issue**: `/blog/meetup-anxiety` was added to sitemap.xml by an auto-generation script, but the page returned 404. Google flagged it as a soft 404.
**Detection lag**: 7 days(caught 2026-05-17 during weekly audit setup)

**Why we missed it**: We ran `sitemaps.submit()` weekly but never `sitemaps.list()` to read back what Google had.

**Plugin response**:
- `gsc-weekly-audit` runs `sitemaps.list()` first and compares against expected sitemap entries
- New default: any sitemap URL returning non-200 → **Critical** alert

## Incident 2026-05-11: Duplicate title from layout template

**Site**: miyakodeit.com
**Issue**: `/blog` page received the title `"Blog | みやこでIT | みやこでIT"` due to layout.tsx `template` running on a page that also set `absolute`. Confused Google.
**Detection lag**: 5 days

**Plugin response**:
- `gsc-weekly-audit` cross-checks sitemap-declared title vs rendered HTML title
- Detects double brand suffix via regex on common patterns:`| {brand} | {brand}`

## Incident 2026-05-22: Cross-page FAQ duplication

**Site**: miyakodeit.com
**Issue**: New page `/guides/kyoto-mokumoku` had 5 FAQ items identical to `/faq` page. Google ignored both FAQs(no rich result on either).
**Detection lag**: 2 days(caught during 3-gate review)

**Plugin response**:
- `jsonld-faqpage --check-duplicates` cross-checks all FAQs across all pages on the same domain
- Default behavior: refuse to generate JSON-LD if any duplicate detected
- Fix-then-go workflow: suggest unique SEO-targeted question rewrites

## Incident 2026-05-24: Discovered, not indexed for 9 new routes

**Site**: miyakodeit.com
**Issue**: Shipped 9 new pages(/case-studies/* + /guides/*). GSC URL Inspection showed all 9 as `Discovered - currently not indexed` 24 hours later.
**Detection lag**: 1 day(would have been longer without this skill's defaults)

**Resolution**: Resubmitted sitemap via API + waited. All 9 indexed within 30 minutes after re-submission.

**Plugin response**:
- `gsc-url-inspect` defaults to inspecting **new** URLs added in the last 14 days
- `sitemap-resubmit` posts a Discord embed after submission with expected indexing window
- Documented the "30-minute typical re-index window" in skill docs

## Incident 2026-05-26: Japanese H1 mobile break

**Site**: miyakodeit.com
**Issue**: H1「京都でIT勉強会・エンジニア交流会を探している方へ」(22 chars) broke at "を探" on mobile 375px — the meaningful particle 「を」 got separated from the verb.
**Detection**: Caught by Designer reviewer subagent during 3-gate review

**Plugin response**:
- `h1-mobile-check`(v0.2) parses H1 and detects mid-particle breaks
- Suggests `<br />` placement that aligns with grammatical units
- Default: H1 length ≤ 15 chars(matches CLAUDE.md project rule)

## Incident 2026-05-27: Half-width space between ASCII and CJK

**Site**: All Netsujo properties
**Issue**: Mixed style: `Vercel デプロイ` (with space) vs `Vercelデプロイ` (no space). Inconsistent across 178 files. Google indexes the text as different tokens, hurting topic clustering.
**Detection**: Caught via grep audit, fixed via perl batch

**Plugin response**:
- `jp-ascii-space-fix`(v0.2) detects and fixes ASCII↔CJK boundary spaces
- Preserves intentional spaces between ASCII pairs(`PR #63`, `Next.js 15`)
- Default mode: dry-run with diff; apply with `--apply`

## Recurring pattern: Weekly mandatory audit

**Rule**(established 2026-05-17, in `miyakodeit/CLAUDE.md`):
> "GSC weekly full audit is mandatory before ANY content shipping. No exceptions."

This is enforced as the **default GitHub Actions workflow** generated by `gsc-weekly-audit --init`:
- Runs every Monday 09:00 JST
- Posts Discord summary with color coding(red/orange/blue)
- Critical findings block deployment workflow until acknowledged

## What we are not yet protecting against

Honest limits of v0.1.0:

- **Schema.org spec changes**: We track the spec but updates are manual
- **AI Overviews ranking signals**: Still opaque; we optimize what's documented
- **Cross-language sites**: Japanese-first; English/Chinese is best-effort
- **JavaScript-rendered content audit**: We trust Next.js SSR output; pure client-side rendering not covered

Future versions will expand coverage. PRs welcome.
